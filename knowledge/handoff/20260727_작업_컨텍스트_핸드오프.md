## 스레드 1. 벤더 운영 대시보드 (7/2~7/9)

**목표**: Metabase(Snowflake db_id=12) 벤더 운영 대시보드. 수요→배송퀄리티→공급→수익성 4섹션.

**상태**: SQL 13종 + 조립 가이드 **완성**, Metabase 카드/대시보드 조립도 **완료**(사용자 직접). 운영 검증 단계.

**핵심 파일**: `projects/260702_벤더_운영_대시보드/조립_가이드.md` (지표 정의·변경이력·배치 가이드 전부 포함) + `sql/` 13개

**확정된 핵심 결정** (상세는 조립_가이드 §3~4):
- **시간 기준 = `CREATED_AT`** (상점 주문 시점). `SUBMITTED_AT`은 배정 실패 시 전체공개 전환 시점 → 사용 금지 (`rules/data_query.md`에 KB화)
- **스코핑 2종**: 수요·퀄리티·수익성 = 권역 접수(`MONITORING_PARTNER_ID`→`ZONES.EXTERNAL_PARTNER_ID`) / 공급 = 벤더 기준(`RAW_VENDORSET`)
- **물량타입**: G4(`SALES_TYPE='직영센터'`, 최우선) → OD(요기요OD) → 법인(메쉬프라임) → 로컬 → 기타. 시리즈는 법인/OD/G4+전체 4개로 통일
- **SLA** = 생성→완료 40분 (`DATEDIFF <= 2400`). `COMPLETE_TIME` 컬럼은 SUBMITTED 기준이라 미사용 (생성 기준 90.9% vs 접수 기준 95.6%)
- **거절률(C3)** = PRD SD2-5/6: 거절건(적극거절20+만료30+수락후취소60) ÷ 완료오더
- **수익성(D)**: 완료건만. 판가=`STORE_BILLABLE_FEE÷1.1`(VAT 제외), 원가=`AGENT_FEE+AGENT_EXTRA_FEE`(VAT 미포함 확정)
- B3 분모=완료건(미배차는 전부 취소 상태로 검증됨), B4는 기타(일반기사) 제외 2시리즈

**발견된 인사이트**:
- 프렌즈 수행건 CM **−2,303원/건** vs 벤더세트 +38원/건 (6/29주, AGENT_EXTRA_FEE 프로모션 영향) → 벤더 공급 확대의 경제적 근거
- 운영 존은 현재 `동대문 1`(EXTERNAL_PARTNER_ID=4563) 하나. 나머지 17개는 QA/테스트

**미결 (다음 할 일)**:
1. **벤더 실원가**: 주간 세트 정산 기준 확정되면 D2/D3의 벤더세트 원가 교체 (현재 기사원가 잠정)
2. **상점 264031** (`[직영A] 스시화 동대문점`): 마스터가 로컬/G3A로 남아있어 G4 분류 12건 누락 — 사용자가 마스터 정정 진행 중. 정정 후 이름기준(1,020) vs SALES_TYPE기준(1,008) 재검증
3. 거절률 세부(동시제안 round SD2-19, 미사용 슬롯 SD2-21)는 미러 플래그 부재로 근사 중
4. (아이디어) 접수전환율(SUBMITTED 도달 비율) = 배차 실패 조기경보 카드 — 제안만 된 상태
