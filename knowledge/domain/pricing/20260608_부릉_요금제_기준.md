# 부릉 요금제 기준 (매출 / 원가)

> 상점 청구(매출) 및 기사 지급(원가) 요금제 기준 정리.
> 메타베이스 `VROONG.DATAMART.ORDERS` 기반 요금 검증 시 참조한다.
> 작성일: 2026-06-08

---

## 1. 매출 요금제 (상점 청구)

- **적용 대상**: `STORE_SALES_DEPARTMENT_ID = 8` 상점 (영업부서 8)
- **검증 컬럼**: `STORE_BASE_FEE` (부가세 10% 포함)
- **거리 기준**: 직선거리 `DISTANCE` (km)

| 구간 | 청구 기준 |
|------|-----------|
| 0km 이상 ~ 1km 미만 | 일괄 4,730원 |
| 1km 이상 | 4,730원 + 1km 초과분 0.1km당 110원 |

- **검증 결과 (2026-05-20~06-07, 파트너 4563)**: 1,084건 중 1,082건(99.8%) 일치. 불일치 2건도 거리 경계 반올림(+110원)으로 실질 오류 아님 → **사실상 100% 규칙 준수**.
- **참고**: `STORE_BILLABLE_FEE`(= base + extra)는 할증·타 요금제가 섞여 전체로 보면 일치율 26%로 낮음. 매출 청구 검증은 반드시 `STORE_BASE_FEE` 기준으로 한다.

## 2. 원가 요금제 (기사 지급) — `AGENT_FEE` 기준

### 2-1. 시간대 구분

| 코드 | 명칭 | 시간 범위 |
|------|------|-----------|
| M+L+PL | 모닝+런치+포스트런치 (주간통합) | 06:00 ~ 16:54 |
| D | 디너 | 16:54 ~ 19:59 |
| PD | 포스트디너 | 19:59 ~ 03:00 |

### 2-2. 기본 거리

- 0km 이상 ~ 1.5km 미만

### 2-3. 기본거리 적용 원가 (요일 × 시간대)

| 요일 | 시간대 | 기본 원가 |
|------|--------|----------:|
| 주중 | 주간통합(M+L+PL) | 3,700원 |
| 주말 | 주간통합(M+L+PL) | 4,000원 |
| 주중 | 디너(D) | 4,100원 |
| 주말 | 디너(D) | 4,300원 |
| 주중 | 포스트디너(PD) | 3,700원 |
| 주말 | 포스트디너(PD) | 3,900원 |

### 2-4. 기본거리 초과 시

- 1.5km 초과분에 대해 **0.1km당 230원 추가** (요일·시간대 무관)

## 3. 검증 전 확정 필요 사항 (미해결)

> 아래 항목이 확정되어야 원가(`AGENT_FEE`) 검증이 가능하다.

| # | 항목 | 이슈 | 비고 |
|---|------|------|------|
| 1 | **시간대 공백** | 03:00 ~ 06:00 구간이 어느 시간대에도 속하지 않음 | PD 연장? 별도? |
| 2 | **시간 산정 기준 컬럼** | 주문생성(`CREATED_AT`) / 배차(`ASSIGNED_AT`) / 픽업(`PICKED_UP_AT`) / 완료(`DELIVERED_AT`) 중 무엇 | 원가 산정 시점 확정 필요 |
| 3 | **주말 정의** | 토·일만? 금요일 디너 포함? 공휴일 처리? | |
| 4 | **거리 기준** | 매출은 `DISTANCE`(직선)로 검증됨. 원가도 동일한지 | 기본거리도 1.5km로 매출(1km)과 다름 |
| 5 | **경계 처리** | 16:54·19:59 정각이 어느 구간에 포함되는지 | |
| 6 | **부가세** | 원가 금액(3,700 등)이 부가세 포함/제외인지 | 마진 계산 시 `AGENT_FEE`는 부가세 미적용으로 처리 중 |

---

## 4. 마진율 계산 기준 (확정)

- **순매출** = `STORE_BILLABLE_FEE / 1.1` (extra 포함, 부가세 제외)
- **원가** = `AGENT_FEE + AGENT_EXTRA_FEE` (기사 extra 포함)
- **마진율** = (순매출 − 원가) / 순매출
- 검증 결과 (파트너 4563): 마진율 **5.1%**, ROI 5.4%, 건당 손익 +233원
