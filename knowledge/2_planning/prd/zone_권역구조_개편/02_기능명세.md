## S2. 영업존 상세 · 등록

- URL: `/sales/zones/{id}` · `/sales/zones/new`
- H1: `영업존 상세` / **`영업존 등록`**
- 하단 버튼: `삭제`(좌) / `목록으로` `저장`(우)

### 섹션 1. 기본 정보

| 필드 | 필수 | 타입 | AS-IS | TO-BE |
|------|:----:|------|-------|-------|
| 영업존 이름 | ● | text | ZONE 이름 | 라벨 변경 |
| 지점 | ● | 검색 드롭다운 | `지점 ID` 라벨인데 지점명 표시 | 라벨을 **`지점`**으로 정정 |

**안내문구**: `» 벤더존 운영방식의 지점만 매핑 가능합니다. 매핑 후에는 다른 지점으로 교체할 수 없습니다.`

- 지점 드롭다운은 **벤더존 운영방식 + 선택 가능한 픽업지 권역이 1개 이상 남은 지점**만 활성화한다.
- 지점의 픽업지 권역이 모두 다른 영업존에 연결돼 있으면 비활성 + 이유 표시(`선택 가능한 픽업지 권역이 없습니다`).

### 섹션 2. 픽업지 권역 선택 ★ 신설

AS-IS의 `권역 정보`(세일즈 권역·공급 권역 disabled 텍스트) 섹션을 대체한다.

| 요소 | 규격 |
|------|------|
| 안내문구 | `» 영업존은 지점의 픽업지 권역 1개로 구성됩니다. 이미 다른 영업존에 연결된 권역은 선택할 수 없습니다.` |
| 픽업지 권역 테이블 | **라디오(단일 선택)** + `픽업지 권역명` / `지역 수` / `연결 상태` |
| 연결 상태 | `선택 가능` / `{영업존명}에 연결됨` (회색, 라디오 비활성) |
| 기본 선택 | 없음 (신규 등록 시 명시적 선택 필요) |
| 검증 | 미선택 시 저장 차단. 문구: `픽업지 권역을 선택해주세요.` |
| 지리 중첩 경고 | 선택한 권역이 **다른 지점**의 픽업지 권역과 겹치면 경고 배너 표시. `⚠ 선택한 픽업지 권역이 {지점명}의 {권역명}과 지리적으로 겹칩니다. 저장은 가능하나 지점 관할 정리가 필요할 수 있습니다.` |

**픽업지 권역 테이블 예시 (성북 지점)**

| ◉ | 픽업지 권역명 | 지역 수 | 연결 상태 |
|:-:|--------------|--------|----------|
| ◉ | 성북 1 zone | 36 | 선택 가능 |
| ○ | YOGIYO_OD | 36 | 성북 1 (요기요OD)에 연결됨 |
| ○ | YOGIYO_DIRECT | 36 | 선택 가능 |

> **왜 지리 중첩을 차단하지 않는가**: 같은 지점의 채널별 픽업지(`YOGIYO_OD` 등)는 지리적으로 같은 지역을 덮는다. 폴리곤 기준으로 중첩을 차단하면 채널 분리 자체가 불가능해진다. 판가 충돌을 막는 실제 장치는 **픽업지 권역 참조의 유일성**이다.

### 섹션 3. 지도 + 지역 목록

| 항목 | AS-IS | TO-BE |
|------|-------|-------|
| 표시 대상 | 세일즈 권역 + 픽업지 전체 + 배송지 | **선택한 픽업지 권역 1개만** |
| 범례 | `세일즈 권역`(파랑) / `픽업지`(노랑) / `배송지`(보라) | **`영업존 권역`(빨강) 단일** |
| 배송지 블록 | 픽업지 아래 별도 블록 (246건) | **제거** — 도착권역 개념 폐기 |
| 미선택 시 | - | 지도 영역에 `픽업지 권역을 선택하면 지도에 표시됩니다.` 플레이스홀더 |
| 지도 위치 | 상단 고정, sticky 아님 | **sticky 처리** |
| 지역 테이블 | `지역종류` / `픽업지명`(오류) | **`지역종류` / `지역명`**. 선택한 권역에 포함된 지역만 |
| 행정동/법정동 | 라디오 (기본 법정동) | 유지 |

### 섹션 4. 상점 판매권역 설정 ★ 신설

| 필드 | 필수 | 타입 | 규격 |
|------|:----:|------|------|
| 배송 반경 | ● | number (km) | 영업존 단일값. 기본값은 전사 기본값 상속 |

**안내문구**: `» 영업존에 속한 G4(직영센터) 상점이 배송을 요청할 수 있는 반경입니다. 픽업지 권역에 반경을 더해 생성되며, 벤더 배송권역과 무관하게 동작합니다.`

- 적용 대상은 **G4(직영센터) 상점 한정**이다. G1~G3 상점의 배송 가능 범위 로직은 변경하지 않는다.
- 상점별 개별 반경 설정은 제공하지 않는다(Out-of-Scope). 영업존 단일값만 관리한다.

### 섹션 5. 이력 정보

AS-IS 없음 → **신설**. 형식은 배송권역 정책의 변경 이력 테이블 방식을 따른다.

**활성/비활성 판정 규칙**: **배송권역이 1개 이상 + 원가 요금제 입력 완료**를 활성 조건으로 한다. (AS-IS의 "해당 ZONE에 영업기준표 연결 여부" 판정은 존 분리로 전제가 사라진다.)

## S7. 탭 2. 벤더 배송권역 ★ 신설

## S8. 탭 3. 원가 요금제 ★ 신설

### 섹션 1. 기본 원가 (고정비)

시간대 차등 없이 정책당 1개 값을 갖는다.

| 필드 | 필수 | 타입 | 기본값 | 배치 |
|------|:----:|------|--------|------|
| 관제비 (VAT 미포함) | | number + VAT 배지 | 0 | 1행 좌 |
| 관리비 (VAT 미포함) | | number + VAT 배지 | 0 | 1행 우 |
| 픽업비 (VAT 미포함) | | number + VAT 배지 | 0 | 2행 좌 |
| 완료비 (VAT 미포함) | | number + VAT 배지 | 0 | 2행 우 |

**안내문구**: `» 관제비·관리비·픽업비·완료비는 시간대 구분 없이 적용됩니다. 라이더비만 요일·시간대별로 설정합니다.`

### 섹션 2. 라이더비 (요일 × 슬롯)

| 필드 | 필수 | 타입 | 규격 |
|------|:----:|------|------|
| 기본 거리 | ● | number (km) | 아래 라이더비가 적용되는 기준 거리 |

**라이더비 매트릭스**

- **행 = 요일 7개** (월~일). 요일 헤더 컬럼은 카키색 배경 (AS-IS 단위물량 표와 동일)
- **열 = 활성 슬롯(최대 5) + `시간 외` 1열**
- 열 헤더에 슬롯명과 시간 범위를 표시 (읽기 전용 — 기본정보 탭에서 정의)
- 셀 = 라이더비 입력 (number, min 0)
- 벌크 입력 툴바를 단위물량 표와 동일하게 제공: `선택 N개` / 값 입력 / `선택 셀 입력` / `선택 해제`

**예시 (성북 1 zone 슬롯 기준)**

| 요일 | 아침<br>09:00~10:55 | 점심피크<br>10:55~14:00 | 점심논피크<br>14:00~16:55 | 저녁피크<br>16:55~20:00 | 저녁논피크<br>20:00~00:00 | **시간 외**<br>00:00~09:00 |
|------|------|------|------|------|------|------|
| 월 | 3,800 | 4,500 | 3,800 | 4,800 | 4,000 | 4,200 |
| … | | | | | | |

**`시간 외` 열 안내**: `» 활성 슬롯이 덮지 않는 시간대(00:00~09:00)에 적용됩니다.`

### 섹션 3. 거리 할증

**적용 상한 거리 단일 필드는 두지 않는다.** 판가의 `거리별 요금`과 동일한 **구간 반복 테이블**로 입력하고, **마지막 구간의 끝이 최대 상한 거리**가 된다.

| 컬럼 | 필수 | 타입 | 규격 |
|------|:----:|------|------|
| 구간 시작 (㎞) | ● | number (읽기 전용) | 첫 행 = **기본 거리** 값. 2행 이후 = **직전 행의 구간 끝** 자동 승계 |
| 구간 끝 (㎞) | ● | number | 직접 입력. 직전 값보다 커야 한다 |
| 단위 거리 (㎞) | ● | number | 예: 0.1 |
| 단위당 원가 (VAT 미포함) | ● | number | 예: 230. 헤더에 `(VAT 미포함)` 표기 (판가 거리별 요금 표와 동일) |
| (행 조작) | | 버튼 | `+` 행 추가 / `−` 행 삭제 (최소 1행 유지) |

**예시 (기본 거리 1.5㎞)**

| 구간 시작 | 구간 끝 | 단위 거리 | 단위당 원가 |
|:---------:|:-------:|:---------:|------------:|
| 1.5 (고정) | 5 | 0.1 | 230원 |
| 5 (자동) | 10 | 0.1 | 300원 |
| 10 (자동) | 15 | 0.5 | 1,200원 |

**안내문구**: `» 마지막 구간의 끝(15㎞)이 거리 할증의 최대 상한입니다. 이를 초과하는 거리에는 추가 가산하지 않습니다.`

> 단일 구간 + 상한 필드로 단순화하려 했으나, 현행 원가·판가가 모두 다구간이라 **구간을 그대로 유지하는 것이 마이그레이션 무손실이고 판가 UI와도 일관**된다. 판가 쪽 컴포넌트를 재사용한다.

### 섹션 4. 원가 요약

| 위치 | 내용 |
|------|------|
| 좌측 제목 | `원가 요약` |
| 좌측 설명 | `고정비 합계 + 라이더비(최고 슬롯) + 거리 할증 전 구간 최대치의 VAT 포함 금액` |
| 우측 상단 | `관제비 0원 + 관리비 150원 + 픽업비 0원 + 완료비 0원 + 라이더비 최고 4,800원 + 거리할증 최대 34,000원` |
| 우측 하단 | `VAT 포함 최대 42,845원` |

**거리 할증 최대치 계산**: 각 구간의 `(구간 끝 − 구간 시작) ÷ 단위 거리 × 단위당 원가`를 전 구간 합산한다.

> AS-IS 요약식은 관제비·관리비를 빼고 합산하면서 문구는 "기본 요금 합계"라 오해를 유발했다. TO-BE는 항목을 전부 명시한다.

### 검증 규칙

| # | 규칙 | 문구 |
|---|------|------|
| 1 | 라이더비 매트릭스 전 셀 입력 필수 | `입력되지 않은 슬롯이 있습니다. ({요일}/{슬롯})` |
| 2 | 기본 거리 > 0 | `기본 거리는 0보다 커야 합니다.` |
| 3 | 거리 할증 구간 1개 이상 | `거리 할증 구간을 최소 1개 입력해주세요.` |
| 4 | 각 구간의 끝 > 시작 | `{N}번째 구간의 종료 거리가 시작 거리보다 작습니다.` |
| 5 | 첫 구간 시작 = 기본 거리 | 기본 거리를 바꾸면 첫 구간 시작을 자동 갱신한다 (사용자 입력 불가) |
| 6 | 구간 연속성 (공백·중복 없음) | 직전 구간 끝을 자동 승계하므로 구조적으로 보장된다 |
| 7 | 활성 슬롯 변경 후 미입력 셀 존재 | `변경된 슬롯의 원가를 입력해주세요.` |
| 8 | CM 하한선 검증 (P1) | `이 원가로는 예상 CM이 하한선(N%)을 밑돕니다. 계속하시겠습니까?` |

### 섹션 5. 적용 원가 할증 선택 ★ 신설

판가 요금제의 `적용 판가 할증 선택`(S3 섹션 4)과 동일한 구조다.

| 요소 | 규격 |
|------|------|
| 안내문구 | `» 이 정책의 배송권역에서 수행되는 오더에 가산될 원가 할증을 선택합니다. 복수 선택 가능합니다.` |
| 테이블 | `#` / `할증명` / `할증 종류` / `원가 금액` / `적용 기간` / `확정 시점` / `삭제` |
| 확정 시점 | `배차 시점` / `완료 시점`(기상 할증) — 예외를 컬럼으로 노출한다 |
| 좌하단 | `+ 할증 추가` (원가 할증 검색 모달) |
| 우측 | `총 N개` + `원가 할증 합계 (VAT 포함) N원` |
| 생성 경로 | 새 할증은 **`원가 할증 관리` 메뉴(S9)에서** 만든다. 이 섹션은 선택·해제만 담당한다 |

| 할증 종류 | `기상` / `요일 및 시간대` / `특수` / **`권역 외`** |
| 원가 금액 | 2줄 `800원` / `(VAT 880원)` |
| 확정 시점 | `배차 시점` / `완료 시점` |
| 적용 정책 | `N개` (적용된 배송권역 정책 수) |
| 시작일자 / 종료일자 | `YYYY-MM-DD` / `-`(무기한) |
| 상태 | `예정` / `진행중` / `종료` |

- 행 클릭 → 상세 화면. 좌하단 `+ 할증 등록`.
- AS-IS 판가 할증 목록의 `대상 ZONE 0개` 표시 결함을 반복하지 않도록, `적용 정책` 컬럼은 백엔드 매핑을 직접 집계한다.

### 상세 · 등록 화면

| 섹션 | 내용 |
|------|------|
| 1. 기본 정보 | 할증명 / 적용 일자 / 적용 시간 / 할증 사유 |
| 2. 금액 정보 | 원가 할증 금액 (VAT 미포함) + VAT 배지. `권역 외` 선택 시 산정 방식 블록 추가 |
| 3. 할증 설정 | 할증 종류 라디오 4개 + 종류별 추가 필드 |
| 4. **적용 배송권역 정책 선택** | 테이블 `#` / `정책명` / `배송권역 수` / `연결 벤더 수` / `삭제`. 좌하단 `+ 배송권역 정책 추가`(모달). 안내: `» 할증은 복수의 배송권역 정책에 적용할 수 있습니다.` |
| 5. 이력 정보 | AS-IS 할증 화면과 동일 포맷 |

- 하단 버튼: `삭제`(좌) / `목록으로` `저장`(우). **등록 화면에는 `삭제`를 넣지 않는다** (AS-IS 결함 B-4 동반 수정).

### 섹션 3 상세. 할증 생성·수정 필드

### 종류별 추가 필드

| 종류 | 추가 필드 | 확정 시점 |
|------|----------|----------|
| 기상 | (권장) 기상 조건 선택 | **완료 시점** |
| 요일 및 시간대 | 요일 7행 × 시간대 2개 (자정 넘김 `24:00~29:59`) | 배차 시점 |
| 특수 | 없음 | 배차 시점 |
| **권역 외** | **산정 방식**: `정액` / `경계 초과 거리 비례`<br>정액 → 금액 1개<br>거리 비례 → `단위 거리(km)` + `단위당 금액` + `상한 금액` | 배차 시점 |

**권역 외 할증 안내문구**: `» 출발지는 적용 정책의 배송권역 안이고 도착지는 밖인 오더에 가산됩니다. 회귀 오더(도착지만 권역 안)에는 적용되지 않습니다.`

> 권역 외 할증은 정책마다 경계가 달라 값도 달라지기 쉽다. 그래도 **정책 전용 할증을 별도 메뉴에서 만들고 1개 정책만 선택**하면 되므로 구조를 나눌 필요는 없다.

> **TBD-5**: 정액/거리 비례 중 무엇을 쓸지, 판가에도 권역 외 할증을 붙일지는 미정. UI는 양쪽을 지원하도록 설계한다.

## S10. 권역 시각화 ★ 신규

- 메뉴 위치: **TBD-6** (`권역 관리` 그룹 신설 vs 기존 그룹 하위)

### 화면 구성

```
┌─────────────────────────────────────────────────────────────┐
│ 필터 바                                                      │
│ [영업존 ☑] [배송권역 ☑]   지점[전체▾] 벤더[전체▾]              │
│                                              [초기화] [검색] │
├──────────────────────────────────────────┬──────────────────┤
│                                          │ 사이드 패널       │
│              NAVER 지도                   │ (호버·클릭 대상)  │
│   빨강 폴리곤 = 영업존                     │ 이름              │
│   파랑 폴리곤 = 벤더 배송권역               │ 지점 / 벤더       │
│                                          │ 픽업지 권역 / 원가 │
│   [범례 박스]                              │ [상세로 이동 ↗]   │
└──────────────────────────────────────────┴──────────────────┘
```

### 인터랙션

| 대상 | 호버 | 클릭 |
|------|------|------|
| 영업존 폴리곤 | 툴팁: 영업존명 + 지점명 + 픽업지 권역명 | 영업존 상세로 이동 |
| 배송권역 폴리곤 | 툴팁: 정책명 + 벤더 수 + 배송권역명 | 배송권역 정책 상세로 이동 |

- 중첩 구간은 **별도 강조 표시하지 않는다.** 파란 폴리곤이 겹쳐 보이는 것으로 충분하며, 정확한 중첩 관계는 배송권역 정책 상세의 `중첩 정책` 컬럼에서 확인한다.
- 하단에 표시 중인 폴리곤 집계(`영업존 N건 / 배송권역 N건`)와 `엑셀 내려받기`를 둔다.

### P1 — CM·CMR

| 항목 | 내용 |
|------|------|
| 영업존 호버 | 전체 CM·CMR + 해당 지역 오더를 수행한 **배송권역 정책별 CM·CMR** 분해 |
| 배송권역 호버 | 소속 벤더가 수행한 오더 기준 CM·CMR |

| 기간 | 기본 최근 1주, 선택 가능 |

## S14. ZONE 원가 요금제 메뉴 폐기

| 항목 | 내용 |
|------|------|
| 대상 | `G4 요금 상품 관리` > `ZONE 원가 요금제 관리` (`/zone/cost-pricings`) |
| 처리 | 원가 요금제가 배송권역 정책 소유로 바뀌므로(S8) **메뉴 자체를 제거**한다 |
