## S1 · S2. 영업존

메뉴: `권역 관리 > 영업존 관리`.

필드·검증: 픽업지 1개 단일 선택, 중복 연결 차단, 지리 중첩 저장 차단.

**제거 (v1.4)**: 영업존 상세의 **상점 판매권역 설정 / 배송 반경** 섹션. 상점 배송 접수 반경은 **기존 상점 설정을 그대로** 따르며 이번 개편에서 변경하지 않는다. 지도에도 판매권역(반경) 오버레이를 그리지 않는다.

목록 컬럼: ID / 영업존명 / 지점명 / 픽업지 권역 / 판가 요금제 / 지리 중첩 / 생성자.

## S3. 판가 요금제

섹션: 기본 정보 / 요금 정보 / 적용 영업존 / 적용 판가 할증 / 이력. v1.3과 동일.

## S4. 판가 할증

메뉴: `요금 상품 관리 > 판가 할증 관리`.

원가 금액 필드 제거. 안내: `» 판가 할증 금액을 입력해주세요. 원가 할증은 [원가 할증 관리]에서 관리합니다.`

## S5. 배송권역 정책 (목록)

메뉴: `벤더 정책 관리 > 배송권역 정책 관리`.

| 컬럼 | TO-BE |
|------|------|
| 관리정책명 | ○ |
| 배송권역 수 | 신설 |
| 연결 벤더 수 | 신설 (세트분배 집계) |
| **원가 요금제** | `선택됨({요금제명})` / `미선택` 강조 |
| 활성 슬롯 수 | 신설 |
| 상태 | 활성/비활성 |

**활성 조건**: 배송권역 ≥1 **+ 원가 요금제 1개 선택**.

## S6. 배송권역 정책 상세

화면: `배송권역 정책 조회 - {정책명}`. 동작: 목록으로 / 예약 저장 / 저장.

### 탭 1. 기본정보

| 섹션 | TO-BE |
|------|------|
| 기본 정보 | 관리정책명 / 상태(자동+사유) / 설명 |
| ~~적용 ZONE~~ | **제거** |
| 보상 조건·금액 | 유지 (+단위·콤마) |
| 세트 물량 구성 | 유지 |

~~슬롯 변경 → 원가표 재입력 경고~~: **삭제** (요금제 독립·시간 구성 불일치 허용).

### 탭 2. 배송권역 매핑

정책에 **이미 생성된** 벤더 배송권역을 연결한다. 신규 생성은 S7 메뉴에서.

| 요소 | 규격 |
|------|------|
| 안내 | `» 벤더 배송권역은 [권역 관리 > 벤더 배송권역 관리]에서 먼저 생성합니다. 여기서는 이 정책에 매핑합니다.` |
| 목록 | # / 배송권역명 / 연동 지점 / 공급권역명 / 면적 / 중첩 정책 / 삭제 |
| 추가 | 검색 모달로 미매핑(또는 타 정책 미소속) 권역 선택. 한 권역은 정책 1개에만 속함 |
| 지도 | 선택 권역 조회 전용 |

### 탭 3. 원가 요금제 선택 ★ (입력 탭 대체)

| 항목 | 내용 |
|------|------|
| 안내 | `» 이 정책에 적용할 원가 요금제 1개를 선택합니다. 요금제 금액·할증은 [원가 요금제 관리]에서 관리합니다.` |
| 선택 | 단일 선택. 검색 모달. 필수 |
| 표시 | 요금제명 / 기본거리 / 활성 여부 / `요금제 상세로 이동` 링크 |
| 미선택 | 저장은 가능하나 **활성 불가** |

### 탭 4. 변경 이력

선택 요금제·매핑·슬롯 변경 이력. 원가 금액 블록은 요금제 쪽 이력에서 조회.

## S8. 원가 요금제 관리 ★ 독립 메뉴

메뉴: `요금 상품 관리 > 원가 요금제 관리`. 목록 + 상세/등록.

### 목록

| 컬럼 | 규격 |
|------|------|
| 요금제명 | ○ |
| 적용 정책 수 | N개 (재사용) |
| 적용 할증 수 | N개 |
| 기본 거리 | ○ |
| 상태 | ○ |

### 상세 섹션

**1. 기본 정보** — 요금제명 / 설명

**2. 고정비** — 관제비·관리비·픽업비·완료비 (단일값)

**3. 기본 원가 (요일 × 시간대)**

| 필드 | 규격 |
|------|------|
| 기본 거리 (km) | 필수 |
| 시간대 구성 | **요금제 자체**에서 정의 (정책 슬롯과 무관). 열=시간 구간 + 시간 외 |
| 표 | 행=요일 7, 열=시간대. 셀=라이더비. 벌크 입력 가능 |

안내: `» 배송권역 정책의 단위물량 슬롯과 시간 구성이 달라도 됩니다. 원가는 이 요금제의 시간 구간만 사용합니다.`

**4. 거리 할증** — 다구간. 마지막 구간 끝=상한. (v1.3 S8 섹션 3과 동일)

**5. 원가 요약** — 고정비+라이더비 최고+거리할증 최대, VAT 포함

**6. 적용 원가 할증 선택**

| 항목 | 내용 |
|------|------|
| 안내 | `» 이 요금제가 적용되는 정책의 오더에 가산할 원가 할증을 선택합니다.` |
| 목록 | # / 할증명 / 종류 / 금액 / 기간 / 확정 시점 / 삭제 |
| 추가 | S9에서 생성한 할증 검색 |

**7. 적용 배송권역 정책 (조회)** — 이 요금제를 선택한 정책 목록 (역참조, 읽기 위주)

### 검증

라이더비 전 칸 필수, 기본거리>0, 거리할증 ≥1행, 구간 끝>시작. (정책 슬롯 연동 검증 없음)

## S9. 원가 할증

메뉴: `요금 상품 관리 > 원가 할증 관리`.

### 목록

할증코드 `YYYYMM-CC###` / 할증명 / 종류 / 금액 / 확정 시점 / **적용 요금제 수** / 기간 / 상태

검색: 원가 요금제 / 할증 종류 / 할증명 / 상태

### 상세

| 섹션 | 내용 |
|------|------|
| 기본 | 할증명 / 종류 |
| 금액 | 원가 할증 금액 (VAT 미포함) |
| 권역 외 | 종류=`권역 외`일 때 **정액 금액만**. 거리 비례 UI **없음**. 안내: `» 원가만 가산되며 판가에는 반영되지 않습니다. 회귀 오더에는 적용되지 않습니다.` |
| 적용 원가 요금제 선택 | 복수. (정책이 아님) |
| 이력 | ○ |

할증 종류별 확정 시점: 기상=완료, 그 외·권역 외=배차.

## S10. 권역 시각화

메뉴: `권역 관리 > 권역 시각화`.

영업존=빨강, 배송권역=파랑. 필터·호버·클릭. 중첩 강조 없음. CM·CMR=P1(목업 제외).

클릭: 영업존→S2, 배송권역→S6 또는 S7.
