## 30초 요약

**문제**: ZONE 하나가 판가와 원가를 동시에 소유하고, 영업 권역과 공급 권역이 한 몸으로 묶여 중첩이 불가하다.

**해결**: 두 축을 분리하고, **영업/공급 역할·메뉴를 나눈다.**

| 축 | 단위 | 구성 | 중첩 | 소유 |
|----|------|------|:----:|------|
| 영업(판가) | **영업존** | 지점 1 + 픽업지 권역 1 | 불가 | 판가 요금제, 판가 할증, 프로모션 |
| 공급(원가) | **배송권역 정책** + **원가 요금제** | 벤더 배송권역 N + 요금제 1 선택 | 권역 중첩 허용 | 정책=매핑·단위물량·보상 / 요금제=기본원가·원가 할증 |

### 메뉴 트리 (v1.4)

```
권역 관리
├ 영업존 관리
├ 벤더 배송권역 관리
└ 권역 시각화

요금 상품 관리
├ 판가 요금제 관리
├ 판가 할증 관리
├ 원가 요금제 관리
└ 원가 할증 관리

벤더 정책 관리
├ 배송권역 정책 관리
├ 세트 분배 관리
└ 벤더 관리
```

### 역할

| 역할 | 담당 메뉴 |
|------|----------|
| **영업 담당자** | 영업존 / 판가 할증 / 판가 요금제 |
| **공급 담당자** | 벤더 배송권역 / 원가 할증 / 원가 요금제 / 배송권역 정책 / 세트분배 |

### 객체 연결 (확정)

선후: **벤더 배송권역을 먼저 생성** → (1) 배송권역 정책에 매핑 (2) 세트분배에서 벤더·세트 수 연결.

| 규칙 | 내용 |
|------|------|
| 원가 요금제 | 정책당 **1개만** 선택. 요금제 1개는 **여러 정책**에서 재사용 |
| 슬롯 | **양쪽 존재**. 정책=슬롯별 단위물량, 요금제=시간대별 기본원가. **시간 구성 일치 불필요** |
| 원가 할증 | **원가 요금제에서만** 설정·선택 |
| 세트분배 | 기준 축 = **벤더 배송권역** (벤더 연결·벤더별 세트 수) |
| 권역 외 할증 | **정액만** + **판가 미반영**(원가만 가산) |

### v1.3 → v1.4 핵심 변경

1. 메뉴 그룹 재편: 권역 관리 / 요금 상품 관리 / 벤더 정책 관리
2. **원가 요금제**·**벤더 배송권역**을 독립 메뉴로 분리 (정책 탭 소유 폐기)
3. 세트분배 축: 배송권역 정책 → **벤더 배송권역**
4. 권역 외 할증: 거리 비례 제거, 판가 미반영 확정 (TBD-5 해소)
5. 슬롯↔원가 동기화 규칙 삭제 (시간 구성이 달라도 됨)
6. 영업존 **상점 판매권역(배송 반경) 설정 제거** — 상점 배송 접수 반경은 **기존 상점 설정 그대로** (변경 없음)
