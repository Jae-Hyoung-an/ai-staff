## 1. 왜 이 미팅이 필요한가 (배경)

벤더 구조의 도입 목표는 **시스템을 통한 운영**이며, 그 전제는 **수요(물량)와 공급(기사)의 예측·통제**다.
동대문 첫 테스트에서 다음이 드러났다.

| 학습 | 시사점 |
|------|--------|
| 각자 이슈 대응만 하고 **주간 S&OP를 실제로 돌리지 않아** 계획-현실 간극이 커짐 | S&OP를 **정례 결정 회의**로 고정해야 함 |
| **계획-실행 단절**(1벤더 계획 → 3벤더 투입) | 계획 대비 실제를 **매주 강제 대조(Reconciliation)** |
| 벤더 발주량 + 벤더 우선 배차가 **프렌즈 버퍼를 잠식** → SLA 붕괴 | **발주량 통제**를 핵심 의사결정으로 |
| 벤더 2곳이 **주중에 이탈**했으나 손쓸 타이밍을 놓침 | **선행지표 + 주중 개입** 장치 필요 |

> 한 줄: **"감과 개인 대응"으로 흘러간 운영을, 주간 사이클의 "예측 → 계획 → 통제 → 학습"으로 되돌리는 회의.**

---

## 2. 목적

| # | 목적 |
|---|------|
| 1 | 차주 **수요를 예측**하고, 그에 맞는 **공급(벤더+프렌즈)을 계획**한다 |
| 2 | **발주량·벤더 구성·상점 오픈 속도**를 본사가 통제 가능한 형태로 **결정**한다 |
| 3 | 지난주 실적을 리뷰하여 **벤더 유지/교체**와 **개선 액션**을 도출한다 |
| 4 | 계획과 실제의 괴리를 조기에 발견하고 **다음 사이클에 반영**한다 (현황 파악 → 조치 반복) |

> 궁극 지표: **총 물량(매출) ↑ + 서비스 레벨(SLA) ↑** 를 동시에.

## 3. 운영 골격

| 항목 | 내용 |
|------|------|
| **단위** | 회의는 **Zone(권역) 단위**로 진행 — 수요·공급·발주·오픈을 Zone별로 본다 |
| **주기** | 매주 **월요일 오후** 메인 미팅(결정 회의) — **월요일 오전까지** pre-read 전부 입력 / 정례 외 **필요 시 주중 개입**(선행지표 임계 이탈 시) |
| **성격** | 메인은 **결정 회의**. 리뷰 데이터는 pre-read로 미리 배포, 회의 시간은 결정에 집중. 회의를 반복하며 **SOP를 정착**시켜 논의 시간을 점진적으로 단축 |
| **참석** | **로컬 영업** · **법인 영업** · 운영 · 플래닝(기획, S&OP 오너) · 프로덕트/데이터 (+ 필요 시 CX) |
| **오너** | 플래닝(기획, S&OP 오너)이 진행·산출물 관리. **발주량 최종 승인자**를 명시 |
| **산출물** | ① 차주 **발주서**(벤더별 세트) ② 벤더 **추가/해지** 리스트 ③ **프로모션 계획** ④ 액션아이템(오너·기한) |

## 4. 아젠다 구성

### 4-1. 메인 미팅 (약 60분)

**1. 현황 파악 (지난주 리뷰)**

| 항목 | 리뷰 | 근거 학습 |
|------|------|-----------|
| **1.1 수요** | ① 예측 vs 실제(요일·슬롯 편차) ② **목표 수요 대비 실제 영업 수요 창출(달성률, 로컬/법인 구분)** | 신규상점 과다예측 / 영업 목표 추적 |
| **1.2 공급** | 계획 발주세트 vs 실제 투입 벤더/기사, 벤더:프렌즈 실제 비율 vs 목표(5:5) + **벤더 스코어카드(① 슬롯 달성 갯수 ② 거절률)** + **프로모션 리뷰**(목표 기여 vs 실제 효과·비용) | 계획-실행 단절 / 버퍼 잠식 |
| **1.3 배송 품질** | SLA(적시율)·미배차/유실, 취소율, 노쇼, 프렌즈 노출률·이탈 | 버퍼 잠식 → SLA 붕괴 |

**2. 차주 Planning**

| 항목 | 결정 | 근거 학습 |
|------|------|-----------|
| **2.1 차주 수요예측** | 과거 트렌드 + 영업 파이프라인(법인/로컬) + 이벤트(경기·날씨·프로모션) | S&OP 본질 복원 |
| **2.2 차주 공급계획·발주 결정** | 차주 수요에 맞춰 필요 공급 산정(적정 1세트 구성·벤더:프렌즈 비율) → 벤더 백로그 확인 → **1.2 벤더 스코어카드** 기반 벤더별 **세트 수 유지·추가·감소** 또는 **계약 해지** 결정 + 프로모션 예정 | 발주량 통제 / 빠른 교체 |

**3. 그 외**

| 항목 | 내용 | 근거 학습 |
|------|------|-----------|
| **3.1 운영/공급 조율** | **상점 오픈 속도(점진 오픈) 판단** — 공급 실질 가능 범위 안에서, 그 외 별도 조율 필요 사항·주중 개입 안건 연계 | 핸드오프 규율 / Stage-Gate |
| **3.2 액션·오너 확정** | 발주량 최종 승인, 액션아이템 RACI | 핸드오프 규율 |

> 차주 수요예측(2.1)은 영업 주체를 분리해 추정: **로컬**(일반 상점) = 상점 수 비례 점진 증가(예측 용이) / **법인**(대형 화주사·거점 상점) = 건당 대규모이나 임의 증대 어려움 → 확정·진행 기반 반영. (정의: `04_배경_위탁지점_전환배경.md`)
> 벤더 평가지표(슬롯 달성 갯수·거절률)는 공급계획(2.2)의 **입력값**으로 사용한다 — 지난주 성적 → 차주 발주/해지 결정.

### 4-2. 주중 개입 (필요 시)

- 정례 회의가 아니라, **선행지표가 임계 이탈**할 때만 개입하는 안전장치 (예: 거절률 급등, 프렌즈 노출률 0 수렴, 벤더 이탈 조짐)
- 개입: 발주/가중치 임시 조정, 벤더 코칭/교체 준비, 권역 축소 등

## 5. 매주 고정으로 보는 핵심 지표

| 영역 | 지표 |
|------|------|
| 수요 | 예측 정확도(MAPE), 실제 물량(요일·슬롯), **목표 수요 대비 영업 창출 달성률(로컬/법인)** |
| 공급/품질 | SLA 적시율, 미배차율, 벤더 **슬롯 달성 갯수·거절률**(스코어카드)·노쇼율 |
| 버퍼 | 프렌즈 제안 노출률, 프렌즈 활성수 추이, 벤더:프렌즈 실제 비율 |
| 경제성 | 건당 원가, 매출, 벤더 인센티브 지급액 |

> 지표는 pre-read 대시보드로 자동화하는 것을 목표로 한다(데이터 소스: Metabase lastmile 등, 추후 확정).

## 6. 운영 원칙

| 원칙 | 설명 |
|------|------|
| **Reconciliation 우선** | "계획 1세트 → 실제 3세트" 같은 괴리를 매주 숫자로 강제 대조 (재발 방지 핵심) |
| **결정 회의** | 리뷰는 pre-read, 회의 시간은 차주 발주·교체·오픈 **결정**에 집중 |
| **발주량 = 버퍼 레버** | 발주량을 통제하지 못하면 안전망(프렌즈)이 먼저 사라진다는 점을 상수로 본다 |
| **선행지표 주중 개입** | 주간 평가는 늦다 → 일·슬롯 단위 지표로 주중에 손쓴다 |
| **점진 확대** | 야심찬 한 방 대신, 게이트 통과 시에만 다음 단계로 |
