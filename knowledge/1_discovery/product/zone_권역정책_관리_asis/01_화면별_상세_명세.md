**툴바 (테이블 위, 별도 배경 박스)**

```

```

- `선택 N개` — 현재 선택된 셀 개수 카운터

- `선택 해제` — 선택된 셀이 없으면 **disabled**

**벌크 입력 동작 순서 (실측)**

1. 셀을 클릭 → 셀에 파란 테두리, 카운터가 `선택 1개`로 변경
2. 값 입력창과 `선택 해제` 버튼이 활성화됨
3. 값을 입력하면 `선택 셀 입력` 버튼도 활성화
4. `선택 셀 입력` 클릭 → 선택된 모든 셀에 같은 값 일괄 반영
5. `선택 해제`로 선택 초기화

## 화면 4. 상세 — 변경 이력 탭

- **URL:** `/vendor/operation-policies/{id}#ChangeHistory` (해시로 탭 상태 관리)
- **하단 버튼:** `목록으로` (저장 관련 버튼 없음)
- **스크린샷:** `03_변경이력_탭.png`

### 테이블 컬럼

| 컬럼 | 내용 |
|------|------|
| 버전 번호 | `v1`, `v2` … |
| 생성 일시 | `YYYY-MM-DD HH:mm:ss` |
| 생성자 | 사용자 표시명 (예: `장석 차장 라이더팀`, `안재형 PO팀`) |
| 상태 | `현재 적용` / `이전 버전` |
| 적용 시작일 | `YYYY-MM-DD HH:mm:ss` |
| 메모 | 변경 메모. 없으면 `-` |
| 관리 | 현재 버전은 `현재 버전` 텍스트(회색), 과거 버전은 `비교` 버튼 |

### 성북 1 zone 실제 이력

| 버전 | 생성 일시 | 생성자 | 상태 | 적용 시작일 | 메모 | 관리 |
|------|----------|--------|------|------------|------|------|
| v2 | 2026-07-21 15:30:22 | 장석 차장 라이더팀 | 현재 적용 | 2026-07-22 06:00:00 | 성북 신규 오픈 (7/22) | 현재 버전 |
| v1 | 2026-07-21 14:07:45 | 안재형 PO팀 | 이전 버전 | 2026-07-21 14:07:44 | - | `비교` |

**여기서 알 수 있는 운영 패턴**

- 저장할 때마다 버전이 쌓입니다 (v1 → v2 …)
- `예약 저장`을 쓰면 **적용 시작일을 미래로 지정**할 수 있습니다
  (v2는 7/21 15:30에 만들었지만 적용은 7/22 06:00부터)
- 일반 `저장`은 적용 시작일이 생성 시각과 거의 같습니다 (v1: 14:07:45 생성 / 14:07:44 적용)
- **v1은 사실상 빈 껍데기**였고 실제 설정은 v2에서 들어갔습니다
  → "정책 껍데기 먼저 생성 → 나중에 실제 값 채우기" 패턴으로 쓰이고 있습니다

## 모달 A. ZONE 검색

- **진입:** 생성/상세 화면의 `+ ZONE 추가` 버튼

### 구성 (상 → 하)

```
┌────────────────────────────────────────┐
│ ZONE 검색                              │
│                                        │
│ ZONE명                                 │
│ [ ZONE명으로 검색        ]      [ 🔍 ] │
│                                        │
│ 검색 결과 (6)                          │
│ ┌──────────┬──────────────────────┐   │
│ │ ZONE ID  │ ZONE명               │   │
│ ├──────────┼──────────────────────┤   │

│           « ‹ 1 › »                    │
├────────────────────────────────────────┤
│ 현재 선택된 ZONE                       │  ← 배경색 다른 영역

│                      [ 닫기 ] [ 선택 ] │
└────────────────────────────────────────┘
```

| 요소 | 규격 |
|------|------|
| ZONE명 검색 | text, placeholder `ZONE명으로 검색` |
| 검색 버튼 | 회색 pill, 돋보기 아이콘 |
| 결과 카운트 | `검색 결과 ( N )` 형식 |

| 버튼 | `닫기`(회색) / `선택`(파란) |

**동작 특성**

- 검색어를 비우고 검색하면 **전체 ZONE 목록**이 나옵니다 (6건)
- **이미 다른 정책에 연결된 ZONE도 그대로 목록에 나옵니다** (필터링 없음)
  → 성북 1·성동 1·동대문 1이 모두 노출됨
