## 이 문서 묶음은 무엇인가

운영 중인 인트라넷에서 **ZONE(벤더존) 운영에 필요한 7개 메뉴**를 직접 열어보고,
필드·기본값·검증 문구·버튼 배치·실제 등록 데이터를 그대로 기록한 **AS-IS 명세**입니다.

기획서(TO-BE)가 아니라 **지금 실제로 돌아가는 화면**의 기록입니다.

이미 작성된 `zone_권역정책_관리_asis/`(같은 `세트 관리` 그룹의 3번째 메뉴)의 **후속 문서**이며,
두 문서를 합치면 벤더존 운영에 필요한 관리자 화면 전체(8개 메뉴)가 커버됩니다.

## 메뉴 지도

```
G4 요금 상품 관리                      ← 요금 체계 (돈)
├─ ZONE 판가 요금제 관리    /zone/sales-pricings    상점에게 받는 요금
├─ ZONE 원가 요금제 관리    /zone/cost-pricings     벤더/기사에게 주는 비용
├─ ZONE 할증 관리           /zone/extra-fees        기상·요일시간대·폴리곤·특수
├─ G4 프로모션 관리         /zone/promotions        특정 상점 대상 할인
└─ ZONE 할증 폴리곤 편집기  /zone/polygons          ※ 조사 제외 (요청 범위 외)

영업 관리                              ← 지리 (땅)
└─ ZONE 관리                /sales/zones            ZONE ↔ 지점 매핑, 권역 확인

세트 관리                              ← 운영 조직 (사람)
├─ 벤더 관리                /vendor/vendors         벤더사·벤더장·소속기사
├─ ZONE 권역정책 관리       /vendor/operation-policies   ※ 별도 문서 존재
└─ 세트분배 관리            /vendor/set-allocations      벤더별 세트 수 배분
```

> **세 그룹이 모두 ZONE을 축으로 연결됩니다.** 하지만 메뉴는 사이드바 3곳에 흩어져 있어,
> 신규 ZONE을 하나 오픈하려면 세 그룹을 왕복해야 합니다. (개선포인트 문서 I-1 참조)

## URL 규칙

| 메뉴 | 목록 | 상세 | 생성 |
|------|------|------|------|
| ZONE 관리 | `/sales/zones` | `/sales/zones/{숫자ID}` | `/sales/zones/**new**` |
| ZONE 판가 요금제 | `/zone/sales-pricings` | `/{숫자ID}` | `/**new**` |
| ZONE 원가 요금제 | `/zone/cost-pricings` | `/{숫자ID}` | `/**new**` |
| ZONE 할증 | `/zone/extra-fees` | `/{숫자ID}` | `/**new**` |
| G4 프로모션 | `/zone/promotions` | `/{숫자ID}` | `/**new**` |
| 벤더 관리 | `/vendor/vendors` | `/{숫자ID}` | `/**add**` |
| 세트분배 관리 | `/vendor/set-allocations` | `/{**Zone UUID**}` | 없음 (ZONE 종속) |
| (참고) ZONE 권역정책 | `/vendor/operation-policies` | `/{숫자ID}` | `/**add**` |

**불일치 2가지:**
- 생성 경로가 `new`(G4·ZONE 관리)와 `add`(세트 관리) 두 종류로 갈림
- 상세 식별자가 숫자 ID(대부분)와 UUID(세트분배)로 갈림

### 검색 조건 URL 쿼리 파라미터

| 메뉴 | 파라미터 |
|------|---------|
| 판가 | `page`, `salesPricingName`, `zoneUuid` |
| 원가 | `page`, `costPricingName`, `zoneUuid` |
| 할증 | `page`, `zoneUuid` (+ 종류·상태) |
| 벤더 | `page`, `businessName`, `status`, `zoneUuid` |
| 세트분배 | `page`, `zoneName` ← 유일하게 **이름 기반** |

> ZONE 필터는 대부분 `zoneUuid`인데 세트분배만 `zoneName`입니다.

## ZONE 중심 연결 구조

ZONE이 모든 설정의 허브입니다.

```
                          지점 (벤더존 운영방식만)
                            │ 1:1, 교체 불가
                            ▼
        ┌──────────────── ZONE ────────────────┐
        │            (현재 6건)                 │
        │                                       │
   [G4 요금 상품]                        [세트 관리]
        │                                       │
        ├─ 판가 요금제   ZONE당 1개              ├─ 권역정책     슬롯·단위물량
        ├─ 원가 요금제   ZONE당 1개              └─ 세트분배     벤더별 세트 수
        ├─ 할증          ZONE당 N개                    │
        └─ 프로모션      ZONE당 N개 (+상점 지정)        ▼
                                                    벤더 (26건)
        [지리 정보]                                    │
        └─ 세일즈 권역 / 공급 권역                      ├─ 벤더장(VO) 1명
           (지점 선택 시 자동 연결, 읽기전용)            └─ 소속기사 N명
           픽업지 폴리곤 / 배송지 폴리곤
```

### 카디널리티 (화면 문구·데이터로 확인)

| 관계 | 제약 | 근거 |
|------|------|------|
| 지점 : ZONE | 1 : 1, 매핑 후 교체 불가 | ZONE 등록 화면 안내문구 |
| ZONE : 판가 요금제 | 1 : 1 | "ZONE별로 1개의 판가 요금제만 적용 가능" |
| ZONE : 원가 요금제 | 1 : 1 | "ZONE별로 1개의 원가 요금제만 적용 가능" |
| 판가/원가 요금제 : ZONE | 1 : N | "요금제는 복수의 ZONE에 적용할 수 있습니다" |
| ZONE : 할증 | 1 : N | 목록에 동일 ZONE 대상 할증 다수 존재 |
| ZONE : 벤더 | 1 : N | 동대문 1에 벤더 4개 |
| 벤더 : ZONE | N : 1 | 벤더 상세의 소속 Zone은 단일값 |
| 벤더 : 벤더장(VO) | 1 : 1 | 벤더장 선택 단일 드롭다운 |
| 벤더 : 소속기사 | 1 : N | 백호 11명 |
| 기사 : 벤더 | 1 : 1 | "타 벤더에 이미 소속된 기사는 등록 제한" |
| 지역 폴리곤 할증 : 폴리곤 | 1 : 1~5 | "최소 1개 이상 최대 5개 이하" |

## 조사 범위와 한계

### 확인한 것

- 7개 메뉴의 목록 화면 전체 (검색 조건 옵션값, 컬럼, 페이지네이션, 등록 데이터)
- 7개 메뉴의 상세 화면 전체 (모든 필드값·기본값·disabled 여부·검증 문구)
- 생성 화면 6개 (세트분배는 생성 화면 없음)
- 모달 5개 (ZONE 검색, 폴리곤 검색, 상점 검색, 세트분배 버전 비교, 지점 드롭다운)
- 탭 구성 (벤더 3탭, 세트분배 2탭)
- 할증 종류 4가지별 폼 변화 (라디오 전환으로 확인)
- ZONE 필터를 통한 요금제-ZONE 실제 매핑 여부 교차 검증

### 확인하지 못한 것

| 항목 | 이유 | 다음에 확인할 방법 |
|------|------|-------------------|
| 저장 / 예약 저장 / 삭제 / 해지 동작 | 운영 데이터 변경 위험으로 클릭하지 않음 | QA 환경에서 테스트 |
| 벤더 ↔ ZONE 연결 경로 | 벤더 등록·상세 화면 어디에도 ZONE 지정 UI가 없음 (이력에는 "존 연결" 기록 존재) | 개발팀 확인 필수 |
| 벤더 상태 전이 규칙 (대기→운영중 등) | 상태 필드가 읽기전용, 전이 버튼은 `운영 중지`/`해지`만 존재 | 개발팀 확인 |
| 할증 `기상 할증`의 기상 조건 설정 | 화면에 비/눈 등 조건 필드가 없음 | 개발팀 확인 |
| `엑셀로 추가` / `코드로 추가` 탭 내부 | 상점 검색 모달의 나머지 2개 탭 미확인 | QA 환경 |
| 폴리곤 편집기 | 요청 범위에서 제외 | 필요 시 별도 조사 |
| 성동·성북의 할증/원가 연결 여부 일부 | 시간상 판가만 전수 확인 | ZONE 필터로 재확인 (5분) |
| 권한별 화면 차이 | PO팀 계정 1개로만 조사 | RM/BTF/라이더팀 계정으로 재확인 |
