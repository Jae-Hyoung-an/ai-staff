들어가며 — 숫자 이전에

상점 물량 · 벤더 SLA는 오늘의 핵심 주제. 하지만 이 숫자들은 목적이 아니라 '수단'이다.

자주 보는 것 (수단)

상점 물량, 벤더 SLA, 당장의 처리율

진짜 목적 (본질)

본사가 물량 · 배차 · 공급을 통제할 수 있는 운영 체계의 정착

숫자 논의에 앞서 — "왜 이 구조인가"를 먼저 정렬한다.

본질 한 장 — "사람 의존"에서 "구조 의존"으로

본질은 한 문장 — 개인기 · 선의에 기대던 운영을, 시스템으로 작동하는 운영으로.

왜 위탁지점을 벗어나려 했나 (AS-IS의 한계)

1완료 건당 fee 구조 → SLA(적시 배송)를 지킬 동인이 없음
2지점이 본사 법인물량보다 본인 수익원인 로컬물량을 우선 처리
3전투배차(기사 자율 선택) → '꿀콜'만 수행, 나머지 오더 방치
4경쟁적 선택 → 전체 최적 배차 불가
51지역 1지점 독점 → 문제 지점 교체 곤란
6개인사업자가 기사 관리 → 퀄리티보다 기사 수익보전 우선 → 필요 공급 안 됨
7영업까지 지점에 위임 → 물량 증대 · 컨트롤 불가

결국 뿌리는 하나

모든 실적이 운영 담당자와 지점장 개인의 역량(개인기)과 선의에 달려 있었다 — 즉 구조가 아니라 사람에 의존하는 운영이었습니다.

그래서 만든 구조 (TO-BE)

1AI 배차(Dispatch Service) 기본 사용 → 최적 배차
2본사가 권역 직접 설계
3예측 물량을 요일 · 시간 단위 세트로 쪼개 다수 벤더에 발주
4벤더 실적을 주간 평가 → 보상 차등 (공급 컨트롤러빌리티 확보)
5소단위 분배 → 미충족 벤더를 부담 없이 빠르게 교체
본사 : 영업(물량) · AI배차 · 공급예측 → 전부 통제
벤더 : 발주받은 물량을 거절 없이 수행 + 필요한 기사 확보

동대문은 끝이 아니라 '시작점'

궁극 목표는 전 지역 전환이고, 동대문은 그 첫 테스트입니다.
그래서 지금 중요한 건 "이번 2주의 점수"가 아니라 "이 구조가 작동하게 만드는 법을 배우는 것"입니다.

지난 2주, 우리가 겪은 문제 (1)

2-1. 초기 진출계획이 시작하자마자 틀어짐

  • 합의했던 권역이 테스트 직후부터 삐걱 → 계속 수정 · 조정
  • 원인: 양측 모두 야심차게, "서로 좋은 사람" 되려 다 된다고만 함 (낙관 편향)

2-2. 첫 S&OP의 실패 — 핵심 학습 지점

  • 기존 물량 예측은 OK. 단, 신규 영업 상점 물량을 과다 예측
  • 의도: 첫 테스트라 프렌즈 버퍼를 크게 (벤더:프렌즈 = 5:5)
  • 플래닝: 50% 벤더 → 1세트 = 벤더 1개면 충분
  • 실제: 계획-실행 단절로 벤더 3개 / 3세트 투입 (과다)

지난 2주, 우리가 겪은 문제 (2)

2-3. CX SOP의 부재

  • 벤더 기사: 배달대행 특유 오더(후불결제 등)에 적응 못함
  • 상점: 이슈 시 본사 콜센터가 아닌 영업사원 · 기사에게 직접 항의
  • 전투배차에 익숙한 상점: 픽업 임박 배차하는 AI배차에 불만
  • "시스템 운영"이 목표였지만 초기엔 사람 손이 너무 많이 들어감

2-4. 기타

  • 준비됐어야 할 프로세스 누락 (예: 주간 정산서 작성) → 시간 소모
  • 후불결제는 프렌즈 불가(앱 모듈 미구현) → 벤더 기사가 처리해야 하나 미숙 → 문제 빈발

다음 사이클, 이렇게 개선하자 (1)

3-1. 초기 진출계획 — 더 촘촘하게

  • 권역 기준을 영업/운영이 명확히 상호 약속하고 설계
  • 야심찬 한 방 대신, 상황 보며 점진적으로 확대
  • 사전 고려 추가: 1·2차 예비 권역, 배상정책, 재이동 · 반납 요율

3-2. 초기 S&OP — 보수적 · 체계적으로

  • 오픈 첫 주는 최소 세트 → 이슈 탐지 · 해결 집중 → 점진적 상점 오픈
  • 주간 S&OP를 실제로 실행 (이번엔 각자 대응만 하다 간극 확대)
  • 물량 예측 + 영업 목표/현황 공유 강화
  • 벤더 성과/보상 기준 강하게, 슬롯 더 촘촘히

다음 사이클, 이렇게 개선하자 (2)

3-3. CX SOP — 본격 구축

  • 개인기가 아닌 시스템 기반 공통 프로세스로 전환
  • 상점 / 벤더(기사) / 프렌즈 / 본사 간 새로운 관계성에 맞춘 대응 SOP 수립

3-4. 벤더 평가 — 선행지표로 '주중' 개입

  • 주간 평가만으로는 늦다 — 이번에도 벤더 2곳이 주중에 이탈, 타이밍을 놓침
  • 일 · 슬롯 단위 선행지표(거절률 · 노쇼 · 적시율 + 배차엔진 체감지표)로 주중 개입 (코칭/발주 조정/교체 준비)
  • 벤더 체감 지표(평균 대기 · 콜 품질)도 함께 추적
