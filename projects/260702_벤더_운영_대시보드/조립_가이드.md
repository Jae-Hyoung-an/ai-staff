## 1. 필터 파라미터 (대시보드 상단)

| 변수 | Metabase 타입 | 위젯 / 기본값 | 비고 |
|------|--------------|--------------|------|
| `zone` | Text | Dropdown (값 소스: `ZONES.ZONE_NAME` 또는 모델). 기본 비움 | 비우면 전체 |
| `start_date` | Date | 기본 비움 | 비우면 전체 |
| `end_date` | Date | 기본 비움 | 비우면 전체 |
| `granularity` | Text | 기본값 `day` (허용 `day`/`week`) | 일/주 토글 |

- `[[ ]]` 안의 변수는 비면 절이 자동 제거되어 "전체"가 됩니다.
- `granularity`는 텍스트라 `DATE_TRUNC('day', ...)`로 치환됩니다.
- 각 질문(네이티브 SQL)에서 변수를 인식시키고, 대시보드 필터 ↔ 카드 파라미터를 연결하세요.

## 3. 지표 정의 (확정본)

- **물량타입**: OD = 관리구분(`MANAGEMENT_TYPE`) `요기요OD` / 법인 = `메쉬프라임` / G4 = `로컬세일즈` + 영업구분(`SALES_TYPE`) `직영센터` / 로컬 = `로컬세일즈`(그 외) / 기타 = 나머지(리셀러 등)
- **40분 완료**: `ORDERS.COMPLETE_TIME <= 2400`초 (완료건 분모). C3는 배차→완료(`DISPATCHED_AT`→`COMPLETED_AT`) 기준
- **취소**: 수요/KPI = `ORDER_STATUS='취소'` / C3 = 세트원장 `DISPATCH_STATUS='30'`
- **거절률 (C3, PRD SD2-5/6)**: 거절건(적극거절 `OUTCOME=20` + 만료 `30` + 수락후취소 `60`) / 완료오더(`DISPATCH_STATUS='20'`)
- **달성세트수**: 완료 슬롯 = `(WEEK_ANCHOR_DATE, DAY_OF_WEEK, SLOT_INDEX)` distinct 중 완료 발생분
- **프렌즈/벤더**: 프렌즈 = `IS_VROONG_FRIENDS_ORDER=true` / 벤더세트 = false (모두 벤더 소속 기사 수행 범위 내)
- **온듀티**: `audit_events`(VENDOR_AGENT) 이벤트 리플레이. SET=벤더(DP-S), FRIENDS=프렌즈전환(DP-F)
