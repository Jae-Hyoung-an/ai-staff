# 존/권역 구조 개편 — 인트라 목업 v1.4

## 한 줄 설명

판가(영업존)와 원가(배송권역 정책·원가 요금제)를 분리하고, 영업/공급 메뉴·역할을 나눈 v1.4 인트라 화면 목업.

## 사용 방법

`index.html`을 브라우저로 엽니다. 설치·서버 불필요.

- 좌측 사이드바로 화면 이동
- 우측 상단 **변경점 강조 표시**로 신규/변경/제거·설계 노트 토글

## 메뉴 트리 (v1.4)

```
권역 관리 — 영업존 / 벤더 배송권역 / 권역 시각화
요금 상품 관리 — 판가 요금제·할증 / 원가 요금제·할증
벤더 정책 관리 — 배송권역 정책 / 세트 분배
```

## v1.3 목업 대비 변경

| 항목 | v1.3 | v1.4 |
|------|------|------|
| 원가 요금제 | 정책 탭 | **독립 메뉴** |
| 벤더 배송권역 | 정책 탭 | **독립 메뉴** |
| 원가 할증 적용 | 정책 | **원가 요금제** |
| 세트분배 축 | (정책) | **벤더 배송권역** |
| 권역 외 | 정액/거리비례 | **정액만 · 판가 미참조** |
| 메뉴 그룹 | 영업/G4/세트/권역 | **권역/요금상품/벤더정책** |

## 제외

CM·CMR, 중첩 시각 강조, 상점별 반경, 폴리곤 직접 편집, 거리 비례 권역 외 — 문서와 동일.
