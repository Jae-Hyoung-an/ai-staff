## 배경

추석 연휴(9/24~9/26)에 상점에서 할증을 수취하고 기사에게 할증 원가를 지급해야 한다. 법인 상점 담당 부서가 화주사별 협의 판가로 법인 할증(판가 1,100 / 원가 1,000)을 먼저 만들어 적용했는데, **btf 3지점(벤더존)은 벤더 원가 구조가 달라 원가를 0원으로 분리**해야 한다. 그래서 3지점 상점만 기존 법인 할증에서 해제하고, 원가 0원인 신규 할증 2종으로 옮긴다.

## 확정된 작업 방식 (사용자 결정 6건)

1. **요기요 OD** 상점 6개는 미적용. 기존 요기요 할증 4종(153162·153166·153168·153173) 유지. 법인영업관리팀이 별도 관리(요기요·부릉 반반 부담).
2. **CU**는 다른 법인과 동일하게 1,100/0으로 전환.
3. 시트에 없는 프랜차이즈(롯데리아·써브웨이·올리브영 등)는 타 상점과 동일하게 **550/0**.
4. 신규 할증은 **판가별 2종**(1,100/0, 550/0)으로 3지점 통합.
5. 적용 기간 **9/24 ~ 9/26**.
6. 상점 상태 구분 없이 전부 대상(삭제 상점만 제외).
