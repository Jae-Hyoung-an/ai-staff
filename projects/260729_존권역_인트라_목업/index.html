존/권역 구조 개편 — 인트라 목업

판가(영업존)와 원가(배송권역 정책)를 분리하는 개편의 화면 목업입니다. 실제 운영 인트라(intra-lite.vroong.com)의 다크 테마·섹션 구조·검증 문구를 그대로 따르고, 변경분만 표시합니다. 좌측 메뉴로 화면을 이동하세요.

우측 상단 변경점 강조 표시를 켜면 신규(신규) · 변경(변경) · 제거(제거) 요소에 표시가 붙고, 설계 의도 노트가 함께 나타납니다. 리뷰 시 켜두는 것을 권합니다.

영업존 상세 변경
영업존 = 지점 1개 + 픽업지 권역 1개. 선택한 권역만 지도에 표시하고, 배송 반경으로 상점 판매권역을 만듭니다.
판가 요금제 관리 변경
통합 요금제 폐기에 따라 적용 영업존 직접 매핑 + 적용 판가 할증 섹션 신설. 목록에서 진입합니다.
원가 요금제 탭 신규
고정비 4항목(단일값) + 라이더비 요일×슬롯 매트릭스 + 거리 할증. 시간 외 열 포함.
벤더 배송권역 탭 신규
기존 적용 ZONE 선택 대체. 중첩 허용, 생성은 지점 공급권역 불러오기만. 직접 그리기 없음.
원가 할증 관리 신규 메뉴
판가/원가 할증 분리. 별도 메뉴로 신설하고 권역 외 할증 신규 타입(정액 / 경계 초과 거리 비례)을 추가합니다.
권역 시각화 신규
영업존(빨강)·벤더 배송권역(파랑)을 한 지도에서 확인. 호버 툴팁 + 클릭으로 상세 이동.

목업에서 직접 조작해볼 수 있는 것

  • 영업존 상세 — 픽업지 권역을 바꿔보세요. 지도·지역 목록·중첩 경고가 함께 변합니다. 배송 반경을 바꾸면 상점 판매권역 경계가 넓어집니다.
  • 원가 요금제 — 라이더비 셀을 드래그로 여러 개 선택한 뒤 벌크 입력을 해보세요. 미입력 셀을 채우면 오류 메시지가 사라지고 원가 요약이 실시간으로 다시 계산됩니다.
  • 거리 할증 구간표 — 구간을 추가·삭제해보세요. 구간 끝을 바꾸면 다음 구간의 시작과 최대 상한 거리가 자동으로 따라옵니다.
  • 원가 할증 조회 — 할증 종류와 산정 방식을 바꾸면 입력 필드가 전환됩니다.
  • 목록 3종 — 판가 요금제·판가 할증·원가 할증 목록에서 이름으로 검색해보세요. 행을 클릭하면 상세로 들어갑니다.
  • 권역 시각화 — 체크박스·지점·벤더 필터로 폴리곤을 걸러보세요. 하단 집계가 함께 바뀝니다.
  • 영업존 추가 / 할증 추가 / 정책 추가 — 검색 모달이 열리고, 이미 연결된 항목은 선택이 막힙니다.

단일 선택으로 확정 · 영업존 : 픽업지 권역 = 1:1입니다. 상점은 픽업지 권역에 귀속되므로, 픽업지 권역 하나가 영업존 하나에만 연결되면 "이 상점의 판가는 무엇인가"가 한 단계로 결정됩니다.

중첩 검증을 지리 기준으로 걸면 안 됩니다 · 같은 지점의 채널별 픽업지(성북 1 zone / YOGIYO_OD / YOGIYO_DIRECT)는 모두 동일한 36개 지역을 덮습니다. 폴리곤 기준으로 중첩을 차단하면 채널 분리가 원천적으로 불가능해집니다. 차단 기준은 픽업지 권역 참조의 유일성이고, 지리적 중첩은 다른 지점과의 관할 중복일 때만 경고합니다.

상한 거리 필드를 없앴습니다 · 별도 적용 상한 거리 없이 마지막 구간의 끝을 상한으로 해석합니다. 첫 구간 시작은 기본 거리를 자동 승계하고, 2행 이후는 직전 구간의 끝을 이어받습니다(입력 불가).

다구간 유지가 무손실입니다 · 현행 원가·판가가 모두 다구간이라 구간을 그대로 이관하면 손실이 없습니다. 단일 구간으로 압축하면 3구간 이상 데이터가 깨집니다. 판가의 거리별 요금 테이블과 UI도 같아집니다.

요약식 정정 · AS-IS 원가 요약은 관제비·관리비를 빼고 합산하면서 문구는 "기본 요금 합계"라 오해를 유발했습니다. 항목을 전부 명시합니다.

기본 거리나 구간 끝을 바꾸면 시작 거리와 상한, 원가 요약이 함께 다시 계산됩니다.
