# 존/권역 구조 개편 — 인트라 목업

## 한 줄 설명

판가(영업존)와 원가(배송권역 정책)를 분리하는 개편의 인트라 화면 목업. 단일 HTML 파일로 브라우저에서 바로 열립니다.

## 사용 방법

`index.html`을 브라우저로 엽니다. 설치·서버 실행이 필요 없습니다.

- 좌측 사이드바로 화면 이동
- 우측 상단 **변경점 강조 표시** 체크박스로 신규/변경/제거 표시와 설계 의도 노트를 켜고 끕니다 (리뷰 시 켜두는 것을 권장)

## 직접 조작해볼 수 있는 것

| 화면 | 조작 |
|------|------|
| 영업존 상세 | 픽업지 권역을 바꾸면 지도·지역 목록·중첩 경고가 함께 변합니다. `YOGIYO_DIRECT`를 선택하면 지리 중첩 경고가 나옵니다 |
| 영업존 상세 | 배송 반경을 바꾸면 상점 판매권역(노란 점선)이 넓어집니다 |
| 원가 요금제 | 라이더비 셀을 **드래그로 여러 개 선택** → 벌크 입력. 미입력 셀을 채우면 오류가 사라지고 원가 요약이 실시간 재계산 |
| 원가 요금제 | 고정비·기본거리를 바꾸면 요약 금액과 검증 문구가 즉시 반영 |
| 원가 요금제 | **거리 할증 구간 추가·삭제.** 구간 끝을 바꾸면 다음 구간 시작과 최대 상한이 자동 승계됩니다 |
| 원가 할증 조회 | 할증 종류·산정 방식 라디오에 따라 안내문구와 입력 필드가 전환 |
| 벤더 배송권역 | 목록 행 클릭 → 지도 선택 권역·우측 패널 변경. 오버레이 체크박스로 레이어 토글 |
| 권역 시각화 | 체크박스·지점·벤더 필터로 폴리곤 필터링, 하단 집계 갱신. 폴리곤 호버·클릭 |
| 판가 요금제 | 기본판가·거리별 요금 변경 시 요약 재계산. `+ 영업존 추가`·`+ 할증 추가`로 검색 모달 |
| 목록 3종 | 판가 요금제·판가 할증·원가 할증 목록에서 이름 검색·초기화. 행 클릭으로 상세 진입 |
| 배송권역 정책 기본정보 | `확인 모달 보기`로 슬롯 변경 경고 모달 확인 |
| 전 화면 | VAT 배지 실시간 계산, 행 삭제 + 카운트 갱신, 저장 시 검증, `목록으로` 버튼 이동 |

## 수록 화면

| 화면 | 유형 | 핵심 변경 |
|------|------|----------|
| 영업존 관리 (목록) | 변경 | 픽업지 권역·판가 요금제·지리 중첩 컬럼 추가. 같은 지점이 여러 행에 나오는 1:N 구조 |
| └ 영업존 상세 | 변경 | **픽업지 권역 1개 단일 선택**, 선택 권역만 지도 표시, 배송 반경 단일값(G4 한정) |
| 판가 요금제 관리 (목록) | **신규 화면** | 적용 영업존 개수 표시 결함 수정, 적용 판가 할증 컬럼 신설 |
| └ 판가 요금제 조회 | 변경 | 적용 영업존 **직접 매핑**, 적용 판가 할증 섹션 신설 |
| 판가 할증 관리 (목록) | **신규 화면** | 원가 컬럼 **제거**, 판가 0원 할증(원가 전용)이 이관 대상임을 표시 |
| └ 판가 할증 조회 | 변경 | 원가 할증 금액 필드 **제거** |
| 원가 할증 관리 (목록) | **신규 메뉴** | 할증코드 `CC` 접두어, 확정 시점·적용 정책 수 컬럼 |
| └ 원가 할증 조회 | **신규 메뉴** | **권역 외 할증** 신규 타입, `적용 배송권역 정책 선택` 섹션 |
| 배송권역 정책 관리 (목록) | 변경 | 배송권역·벤더·원가·슬롯 컬럼 추가, 활성 판정 규칙 변경 |
| └ 기본정보 탭 | 변경 | 적용 ZONE 선택 섹션 제거, 라벨·단위 정정, 슬롯 변경 경고 |
| └ 벤더 배송권역 탭 | 신규 | 중첩 허용, **지점 공급권역 참조 전용**(조회 전용 지도) |
| └ 원가 요금제 탭 | 신규 | 고정비 4항목 + **라이더비 요일×슬롯 매트릭스** + **거리 할증 다구간표** + 적용 원가 할증 선택 |
| 권역 시각화 | 신규 | 영업존·배송권역 폴리곤, 호버 툴팁, 필터 (P0) |

> 배송권역 정책 상세 탭은 **4개**입니다(기본정보 / 벤더 배송권역 / 원가 요금제 / 변경 이력). 원가 할증은 별도 메뉴로 빠졌습니다.

## 목업의 성격

- **디자인 시안이 아닙니다.** 실제 운영 인트라의 다크 테마·섹션 구조·검증 문구를 재현해 "무엇이 어떻게 바뀌는지"를 합의하기 위한 도구입니다.
- 지도는 NAVER 지도 대신 SVG로 대체했습니다. 폴리곤 모양은 실제 권역이 아닙니다.
- 데이터는 실제 운영값(성북 1 zone 슬롯·단위물량, 동대문 원가 구간 등)을 최대한 반영했으나 일부는 예시입니다.
- 입력값은 화면 안에서만 반영되며 저장되지 않습니다.

## 이번 버전에서 제외한 것

| 항목 | 사유 |
|------|------|
| 배송권역 중첩 구간 시각적 강조 | 폴리곤이 늘어날 때 판독성 저하. 중첩 관계는 `중첩 정책` 컬럼으로 확인 |
| CM·CMR 표시 및 하한선 경보 | P1 항목이므로 이번 목업 범위 밖 |
| 상점별 개별 배송 반경 | Out-of-Scope. 영업존 단일값만 관리 |
| 배송권역 폴리곤 직접 그리기·편집 | 지점 공급권역 참조 단일 방식으로 확정. 폴리곤 수정은 `권역 관리`에서 원본을 고친다 |
| 거리 할증 `적용 상한 거리` 필드 | 다구간 테이블의 **마지막 구간 끝**이 상한 역할을 한다 |
| ZONE 원가 요금제 메뉴 | 배송권역 정책의 원가 요금제 탭으로 이관되어 폐기 대상 |
