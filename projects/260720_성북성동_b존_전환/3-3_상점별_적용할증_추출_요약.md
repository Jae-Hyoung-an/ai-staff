## ⚠️ 3-3 실행 시 핵심 주의사항

1. **할증 원가 0원 변경은 "할증 단위"로 하면 안 됨.**
   CU 우천할증(#135913), GS25 우천할증(#59880) 같은 **프랜차이즈 공통/전국 할증**은 권역 외 상점들도 함께 쓰고 있어, 할증 자체의 원가를 0원으로 바꾸면 전국에 영향이 감. → **상점-할증 매핑 해제** 또는 존 전용 할증만 선별 변경 필요. 존 전용(성동행당/성북동선 명명) 할증과 공통 할증을 구분하는 작업 선행 필요.
2. **#98205 (천안 폴리곤, 130개 상점 매핑)** — 잘못된 레거시 매핑으로 보임. 이관과 무관하게 정리 대상. 폴리곤 조건이 서울에서 발동하지 않아 실효는 없을 가능성이 높지만, 이관 시 함께 정리 권장.
3. **단기 프로모션 할증(7/21~22 종료)** 은 이관 시점(오픈일)에 이미 만료되었을 수 있음 → 실행 직전 재추출 필요.
4. **이 목록은 상점 직접 매핑(`EXTRA_FEE_STORE`) 기준.** 상점 매핑 없이 지역(REGION)·폴리곤 조건만으로 자동 적용되는 할증이 별도로 존재할 수 있음 (`EXTRA_FEE_REGION`, `EXTRA_FEE_POLYGON`). 3-3 실행 범위 확정 시 추가 확인 필요.
