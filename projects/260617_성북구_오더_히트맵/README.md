# 성북구 오더 히트맵 (인터랙티브)

성북구 및 인접 지역 상점의 위치·최근주문수를 지도 위 히트맵으로 시각화한 결과물입니다.

## 실행 방법
- `index.html` 파일을 더블클릭하면 기본 브라우저에서 바로 열립니다.
- 지도 타일/라이브러리를 CDN에서 불러오므로 **인터넷 연결**이 필요합니다.

## 데이터 요약
- 상점 5,167개 (3개 자료 병합)
  - 성북구_데이터.csv (배민 Y/N)
  - 260618_성북성동기존오더.csv (기존오더)
  - 성동구데이터.xlsx (배민 Y/N, 가게배달 가격 포함)
- 구분별: 가게배달 Y=1,570, N=2,190, 기존오더=1,407
- 범위: 성북·성동 중심 + 강북·동대문·종로·광진 일부
- 히트맵 강도(주문수 가중)는 현재 표시 대상 기준으로 정규화 → 각 보기에서 색 대비가 최대화됩니다. (자료별 주문수 척도가 달라 보기별 자체 정규화를 사용)

## 인터랙션 (우측 상단 패널)
| 항목 | 옵션 |
|------|------|
| 히트맵 강도 기준 | 주문수 가중 / 상점 밀도(균등) |
| 표시 대상 | 전체 오더 / 배민 자료 전체(Y·N) / 가게배달만(Y) / 기존오더만 |
| 경계 표시 | 행정동 경계 on·off / 자치구(구) 경계 on·off |
| 상점 위치 점 표시 | on·off (마우스 오버/클릭 시 상호명·구분·주문수·가게배달 가격 표시, 구분별 색상) |

> 가게배달 가격은 성동구 자료에만 포함되어 있으며, 정보가 없는 상점은 공란으로 표시됩니다.

## 다시 만들기 / 다른 데이터 적용
이 파일은 `tools/heatmap_builder/build_heatmap.py` 로 생성되었습니다.

```powershell
python tools/heatmap_builder/build_heatmap.py
```

## So What (활용)
- **주문 핫스팟 식별**: 색이 가장 진한 지역이 주문이 집중되는 곳 → 배달 커버리지·기사 배치 우선순위 검토.
- **배달 가능 매장과의 갭 확인**: `가게배달 Y만` 보기와 `전체` 보기를 비교하면, 주문은 많지만 가게배달 매장이 적은 공백 지역을 찾을 수 있음 → 입점/배달 전환 타깃 후보.
